# 📋 Suivi des Problèmes et Résolutions

Ce dossier contient les fiches de suivi pour tous les problèmes techniques, bugs ou défis architecturaux rencontrés lors du développement de l'application de gestion de budget.

## Format des fiches

Chaque problème doit faire l'objet d'un fichier `.md` nommé `ISSUE-XXX.md` avec la structure suivante :

---
### 🆔 ID: ISSUE-XXX
**Titre :** [Description courte du problème]  
**Date :** AAAA-MM-JJ  
**Sévérité :** [Bloquant / Majeur / Mineur]  
**Statut :** [Ouvert / En cours / Résolu]

#### 📝 Description
Description détaillée du problème, contexte et étapes pour le reproduire.

#### 🔍 Analyse
Pourquoi ce problème est-il survenu ? Quelles étaient les causes racines ?

#### ✅ Résolution
Description de la solution appliquée. Inclure des références aux commits ou aux fichiers modifiés.

#### 💡 Leçons apprises
Comment éviter ce problème à l'avenir ?
---
